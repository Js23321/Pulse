# Pulse

Pulse is a focused productivity workspace designed to help people build consistent routines and track meaningful progress over time.

Instead of switching between multiple apps for habits, workouts, study sessions, coding practice, goals, and notes, Pulse brings everything together into a single daily workflow built around clarity and consistency.

---

## Features

### Daily Habits
Track recurring habits with a simple daily check-in system and visible streaks that encourage long-term consistency.

### Progress Tracking
Log incremental progress across different areas such as:
- workouts
- coding
- studying
- reading
- personal goals

Pulse is designed to make progress easy to record without adding unnecessary complexity.

### Pulse AI
Integrated AI assistance available directly from the top navigation on desktop and mobile.

Use Pulse AI for:
- planning
- motivation
- daily reflection
- accountability
- quick guidance

### Notes
Keep daily notes, ideas, and reflections connected to your progress in one place.

---

## Philosophy

Pulse is built around sustainable progress.

The goal is not to optimize every minute of the day, but to create a system that is calm, consistent, and easy to return to every day.

Small actions repeated over time create momentum.
